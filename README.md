# Thinklify EdStep – 8051 Reasoning System

## Overview
A deterministic guided learning system that helps users understand concepts through structured questioning instead of direct answers.

## Problem
Most learning systems provide answers directly, which reduces deep understanding—especially for neurodivergent learners.

## Solution
This system:
- Keeps the user within a domain (8051 concepts)
- Asks progressive, logic-based questions
- Reinforces learning step-by-step

## Example Flow
User: Pointer  
System: What do you know about pointer?  
User: Address  
System: What does it point to?

## Features
- Domain-restricted reasoning
- Adaptive questioning flow
- Concept reinforcement

## Tech Stack
- Flutter (UI)
- Rule-based reasoning engine
